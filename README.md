# devcontainer-features

A collection of reusable [Dev Container Features](https://containers.dev/implementors/features/).

## Features

### `mcp-grafana`

Installs the official Grafana MCP server v0.14.0 for Linux `amd64` and `arm64`.

```json
{
  "features": {
    "ghcr.io/dotsent/devcontainer-features/mcp-grafana:1": {}
  }
}
```

### `migrate`

Installs the `golang-migrate` CLI v4.18.2 for Linux `amd64` and `arm64`.

```json
{
  "features": {

  }
}
```

### `websocat`

Installs [websocat](https://github.com/vi/websocat) — a command-line WebSocket client — from GitHub releases. Works on `amd64` and `arm64` (Apple Silicon / OrbStack).

#### Usage

In your `devcontainer.json`:

```json
{
  "features": {
    "ghcr.io/dotsent/devcontainer-features/websocat:1": {}
  }
}
```

To pin a specific version:

```json
{
  "features": {
    "ghcr.io/dotsent/devcontainer-features/websocat:1": {
      "version": "1.12.0"
    }
  }
}
```

#### Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `version` | string | `1.13.0` | websocat release version to install |

#### Example

```bash
# Connect to a WebSocket endpoint
websocat ws://localhost:4000/ws/relay/my-session

# Send messages from a pipe
(echo '{"type":"setup"}'; sleep 1; echo '{"type":"prompt","text":"hello"}') \
  | websocat ws://localhost:4000/ws/relay/my-session
```

## Publishing

Features are published automatically to [GitHub Container Registry](https://ghcr.io) when a version tag is pushed:

```bash
git tag v1.0.0
git push origin v1.0.0
```

The `release.yml` workflow uses [`devcontainers/action@v1`](https://github.com/devcontainers/action) to package and push each feature under:

```
ghcr.io/<repo-owner>/devcontainer-features/<feature-name>:<version>
```

## Local reference (before publishing)

You can reference the feature directly from a local path during development:

```json
{
  "features": {
    "./features/websocat": { "version": "1.13.0" }
  }
}
```

## Development

### Repository structure

```
src/
  websocat/
    devcontainer-feature.json   # Feature metadata and options
    install.sh                  # Installation script
test/
  websocat/
    scenarios.json              # Test scenarios (default + pinned version)
    test.sh                     # Test assertions
.github/workflows/
  release.yml                   # Publish on tag push
  test.yml                      # CI tests on PR / push to main
```

### Running tests locally

Requires Docker and [`@devcontainers/cli`](https://github.com/devcontainers/cli):

```bash
npm install -g @devcontainers/cli

# Test against Debian Bookworm
devcontainer features test \
  --skip-autogenerated-test \
  --features websocat \
  --base-image debian:bookworm \
  .
```
